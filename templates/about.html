About HeartCare AI

Heart disease prediction made easier to understand.

HeartCare AI is a B.Tech final year project that combines Flask, Python, machine learning, and a guided web interface to support educational heart disease risk screening.

91.85% Model accuracy
95.33% ROC AUC score
11 Features used
Flask + Python KNN · Random Forest · XGBoost SQLite database
Project Type B.Tech Final Year
Institution G.E.C Buxar
Department ECE
Year 2026

Project Focus

Built for learning, clarity, and practical screening workflows.

Guided Prediction

Users can enter clinical indicators through a structured form and receive a clear screening output.

ML Comparison

The project compares KNN, Random Forest, and XGBoost to select a strong prediction model.

Admin Supervision

Admins can review users, monitor prediction history, and supervise model information from one dashboard.
